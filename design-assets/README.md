## Workflow

1. Récupérer les images (Unsplash, photographe interne, etc.)
2. Optimiser (max 2400px de large, JPEG qualité 80) — Shopify ne ré-encode pas tout.
3. Uploader via `Admin → Content → Files`.
4. Dans le Customizer, pour chaque section, cliquer `Select image` puis choisir l'image uploadée.
